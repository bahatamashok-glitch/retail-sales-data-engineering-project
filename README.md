#  Retail Sales Lakehouse Project

##  Project Overview

This project demonstrates an end-to-end Retail Sales Data Engineering pipeline using the Medallion Architecture in Azure Databricks.

The pipeline ingests raw retail sales data, processes it through Bronze, Silver, and Gold layers using PySpark and Delta Lake, and generates business dashboards for analytics.
